# JellyJam Portfolio

A modern, interactive portfolio website showcasing game development projects with live statistics and integrations.

## Features

- **Interactive Project Showcase**: Grid-based project cards with detailed modal views
- **Live API Integration**: Real-time statistics from multiple platforms
  - YouTube Data API for subscriber/view counts
  - Thunderstore API for mod download statistics
  - Steam widget integration for game pages
- **Responsive Design**: Mobile-friendly layout with Tailwind CSS
- **Smooth Navigation**: Animated scrolling between sections
- **Modern Tech Stack**: React 18 + Vite + TypeScript

## Projects Featured

1. **Boxception** - Game development project with Steam integration
2. **Tiny Company** - Lethal Company mod with Thunderstore statistics
3. **JellyJam Channel** - YouTube channel with live subscriber metrics

## Tech Stack

- **Frontend**: React 18, Vite, TypeScript
- **Styling**: Tailwind CSS, PostCSS
- **APIs**: YouTube Data API v3, Thunderstore API, Steam Widgets
- **Deployment**: GitHub Pages
